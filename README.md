# วันธรรมดา (Ordinary Day)

เกม zombie survival แนว open-world sandbox มุมกล้อง isometric 3D เล่นบนเว็บเบราว์เซอร์ ทั้งมือถือและคอม หายนะเริ่มต้นจากเช้าวันอังคารธรรมดา ผู้เล่นเกิดมาตัวเปล่า กลางวันออกหาของ กลางคืนเอาชีวิตรอด

**สถานะ:** Prototype v0.3

## เล่นเกม

- **บนเครื่อง:** ต้องเปิดผ่าน dev server เช่น `npx serve .` หรือ `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000` (ต้องต่ออินเทอร์เน็ต เพราะโหลด Three.js และฟอนต์จาก CDN)
- **ดับเบิลคลิก `index.html` ใช้ไม่ได้แล้ว** เพราะเบราว์เซอร์ไม่โหลด ES modules จาก `file://` หน้าเริ่มเกมจะขึ้นข้อความบอกวิธีเปิดแทน
- **GitHub Pages:** Settings → Pages → Source: `main` branch, โฟลเดอร์ `/ (root)` แล้วจะได้ลิงก์เล่นที่อัปเดตทุกครั้งที่ push

## เป้าหมาย

รอดให้ครบ 7 คืน (คืนหนึ่งนับเมื่อถึง 06:00 ของเช้าถัดไป) แล้วตั้งแต่เช้าวันที่ 8 เฮลิคอปเตอร์กู้ภัยจะลงจอดที่สี่แยกมุมสวนสาธารณะ ทุกวันเวลา 08:00–12:00 มีลูกศรใต้นาฬิกาชี้ทางและบอกระยะ เดินเข้าไปในวงลงจอดเพื่อชนะ ถ้าไปไม่ทันจะกลับมาใหม่วันถัดไป

## เหตุการณ์ประจำวัน (v0.8)

วันที่ 2–7 แต่ละวันมีอย่างน้อย 1 เหตุการณ์ สุ่มใหม่ทุกเกม
- **เสบียงทิ้งจากฟ้า (กลางวัน 10:00–15:00):** กล่องลงที่สี่แยกห่างผู้เล่น 20–70 ม. มีของ 6 ชิ้นรอบกล่อง (อาวุธ กระสุน 2 ยา อาหาร น้ำ ระดับ Civilian เพราะของ Police / Military เกิดเฉพาะกลางคืนตามที่ยืนยันไว้) เป็นสี่เหลี่ยมเขียวบนแผนที่ มี Walker เดินมาดู 3 ตัว กล่องหายเช้าวันรุ่งขึ้น
- **ฝูงซอมบี้ (กลางคืน ตั้งแต่วันที่ 3):** วิทยุเตือนตอน 19:00 แล้วราว 21:00–23:30 ฝูง 5 + วันที่ (ไม่เกิน 12) เดินตามถนนใหญ่เส้นหนึ่งข้ามเมืองแล้วออกไป เห็นบนแผนที่ทุกระยะ ถ้าเจอผู้เล่นหรือได้ยินเสียงจะแยกมาไล่
- **ไฟดับ (กลางคืน):** ตั้งแต่ 19:00 ถึงเช้า ไฟถนนและไฟในตึกดับ เหลือไฟฉาย

## ตั้งค่า (v0.8)

ปุ่ม "ตั้งค่า" ในหน้าหยุดเกม และลิงก์บนหน้าเริ่มเกม: คุณภาพกราฟิก (สูง / กลาง / ต่ำ: ความละเอียดสูงสุด 2 / 1.6 / 1 เท่า เงาเปิด / เปิด / ปิด) เสียงรวม เพลง เสียงเอฟเฟกต์ และแสดง FPS จำไว้ในเบราว์เซอร์ ค่าเริ่มต้น: คอม สูง มือถือ กลาง

## เพลง (v0.8)

เพลงสังเคราะห์ ไม่มีไฟล์: คอร์ดนุ่ม ๆ ตอนเช้าก่อนการระบาด คอร์ดไมเนอร์หลังการระบาด เสียงต่ำมืดและเสียงหึ่งตอนกลางคืน และเสียงหัวใจเต้นที่เร็วและดังขึ้นตามจำนวนซอมบี้ที่ไล่อยู่ (สูงสุดเมื่อ 4 ตัว)

## ความตึงเครียด (v0.7)

- **ของหายากขึ้น:** โอกาสที่จุดว่างจะมีของใหม่ลดลงวันละ 15% (ไม่ต่ำกว่า 40% ของวันแรก) และทุก 06:00 ของที่วางอยู่ไกลผู้เล่นเกิน 25 ม. มีโอกาส 35% ถูกผู้รอดชีวิตคนอื่นเก็บไป ยกเว้นจุดข้างรถตำรวจ รถทหาร รถพยาบาล และของที่ผู้เล่นทิ้งเอง
- **ได้กลิ่น:** อยู่ตึกเดิมนานเกิน 90 นาทีในเกมตอนกลางคืน ซอมบี้ที่ใกล้ที่สุดในระยะ 40 ม. จะมาที่ตึกทุก 45 นาที (เพิ่มทีละตัวทุก 2 ชั่วโมง สูงสุด 3) แล้วพังประตู ย้ายตึกแล้วนับใหม่
- **ซ่อมประตู (v0.42 ไม่ใช้ไม้กระดาน):** ประตูที่พังซ่อมได้ด้วยปุ่ม B / 🔨 ได้ความทน 60 เสียงดังเรียกซอมบี้
- **ย่อง:** เดินช้า ซอมบี้ที่ยังไม่ได้ไล่จะเห็นคุณในระยะแค่ครึ่งเดียว

## ตึกที่เข้าได้

บล็อกเมืองทุกบล็อกมีตึก 1 หลังที่เข้าไปได้ (รวม 11 หลัง) สังเกตจากป้ายไฟสีส้มเหนือประตู เดินเข้าไปแล้วหลังคาและผนังด้านบนจะหายไปให้เห็นข้างใน มีเฟอร์นิเจอร์และจุดเกิดของ 2 จุด กด E หรือแตะปุ่มประตูเพื่อเปิดปิดประตู

- ซอมบี้มองทะลุผนังและประตูที่ปิดไม่ได้ จะรู้ตัวก็ต่อเมื่อเห็นผ่านประตูที่เปิดอยู่ หรือคุณอยู่ชิดผนังห่างไม่เกิน 2.5 เมตร
- เสียงที่เกิดในตึกที่ปิดประตูดังออกไปแค่ครึ่งเดียว แต่ถ้าซอมบี้ได้ยินหรือเห็นคุณวิ่งเข้าตึก มันจะเดินอ้อมมาหาประตูและพังประตูที่ปิดไว้
- ประตูทนได้ 120 หน่วยดาเมจ (ซอมบี้ตีครั้งละเท่าดาเมจที่ตีผู้เล่น) Tyrant พังในทีเดียว ระเบิดของ Boomer ทำประตูเสีย 60 ประตูที่พังแล้วปิดไม่ได้จนกว่าจะเริ่มเกมใหม่
- ตีหรือโดนตีผ่านผนังไม่ได้ ระเบิดและการทุบของ Tyrant ไม่ทะลุผนัง

## ระดับความยาก

เลือกได้ที่หน้าเริ่มเกม (ง่าย / ปกติ / ยาก) ใช้กับเกมใหม่ เกมที่เซฟไว้ใช้ระดับเดิม สถิติดีสุดแยกตามระดับ ระดับความยากปรับเฉพาะค่าที่ยังเป็น placeholder: ดาเมจที่ผู้เล่นโดน (×0.6 / ×1 / ×1.4), จำนวนซอมบี้ที่เกิดกลางคืนต่อรอบ (−1 / 0 / +1), โอกาสติดเชื้อ (×0.5 / ×1 / ×1.5) และความเร็วที่หิวกระหาย (×0.7 / ×1 / ×1.3) HP ซอมบี้และเวลากลางวันกลางคืนที่ยืนยันแล้วไม่เปลี่ยน

## หิวและกระหาย

เอาออกแล้วใน v0.42 HP ฟื้นเองเมื่อไม่โดนตี 6 วินาที แต่ช้าและถึงแค่ 60% ที่เหลือต้องใช้ยา

## อาวุธประชิดสึกหรอ

ไม้เบสบอล มีด ท่อเหล็ก กระบองตำรวจ และขวาน มีความทนเป็น % แสดงในช่องอาวุธและกระเป๋า ลดลงทุกครั้งที่ตีโดน หมดแล้วอาวุธพัง กลับไปใช้หมัดซึ่งไม่พัง อาวุธที่เก็บได้มีความทน 40–100% ของดรอปการันตีจาก Armor Walker / Tyrant เต็ม 100% (จำนวนครั้งที่ตีได้เป็น placeholder)

## ศัตรูพิเศษ

- **Armor Walker:** เกราะลดดาเมจปืนเฉพาะด้านหน้า ยิงจากด้านหลังได้ดาเมจเต็ม
- **Tyrant:** ถ้าติดรถ กองขยะ หรือม้านั่ง จะทุบพังเป็นทางผ่าน (ตู้คอนเทนเนอร์และตึกไม่พัง) ของที่พังจะเซฟไว้และกลับมาเมื่อเริ่มเกมใหม่

## การติดเชื้อ

ซอมบี้ที่กัดมีโอกาสทำให้ติดเชื้อ (Walker 10% · Zombie, Sprinter, Armor Walker 20% · ระเบิดของ Boomer และการทุบของ Tyrant ไม่ติดเชื้อ ค่าเหล่านี้เป็น placeholder) เชื้อลามจาก 0% ถึง 100% ใน 8 ชั่วโมงในเกม (ราว 100 วินาทีจริงที่ ×1) ระหว่างติดเชื้อ HP ไม่ฟื้นเอง ถึง 100% จะกลายเป็นซอมบี้และจบเกม Antibiotic รักษาได้ (ใช้ได้แม้ HP เต็ม และปุ่มรักษาจะเลือก Antibiotic ก่อนเมื่อติดเชื้อ) Resurrection Kit ที่ทำงานก็ล้างเชื้อด้วย

## แผนที่

แผนที่เล็กใต้แถบ HP มุมซ้ายบน หมุนให้ตรงกับมุมกล้อง (ด้านบนของแผนที่คือด้านบนของจอ) แสดงถนน บล็อก ตึก (ตึกที่เข้าได้เป็นกรอบกลวง ประตูสีส้มคือเปิด สีน้ำตาลคือปิด สีแดงคือพัง) สวน รถตำรวจ (ฟ้า) รถทหาร (ทอง) รถพยาบาล (กากบาทแดง จางลงเมื่อเก็บชุดชุบชีวิตไปแล้ว) จุดลงจอดเฮลิคอปเตอร์ในเช้าที่มารับ Tyrant (จุดแดงกะพริบ) และซอมบี้ที่อยู่ใกล้ไม่เกิน 18 เมตร ลูกศรสีอำพันคือผู้เล่นและทิศที่หัน ขนาด 152px บนจอคอม 78px บนมือถือ

## คำแนะนำสำหรับผู้เล่นใหม่

เอาออกแล้วใน v0.42 เกมไม่มีคำอธิบาย นาฬิกา หรือข้อความประกาศบนจอ เวลาและเหตุการณ์บอกด้วยแสง เสียง และสิ่งที่เกิดขึ้นในเมือง

## รถพยาบาล

มีรถพยาบาลจอดทิ้งไว้ฝั่งตะวันตกของตลาด หลังรถมี Resurrection Kit 1 ชุดทุกเกม (ไม่เติมใหม่ระหว่างเกม) โอกาสดรอป 1% ของ Resurrection Kit ในตารางยายังเหมือนเดิมตามที่ยืนยันไว้

## เล่นกับเพื่อน (v0.12)

เล่นด้วยกันได้สูงสุด 4 คน ผ่านอินเทอร์เน็ต ไม่ต้องสมัครหรือติดตั้งอะไร

1. **คนเปิดห้อง (host):** เริ่มเกมตามปกติ (เกมใหม่หรือเล่นต่อจากเซฟ) กดหยุดเกม แล้วกด **เปิดห้องให้เพื่อนเข้า** จะได้รหัสห้อง 5 ตัว เช่น `C5GQE`
2. **เพื่อน:** เปิดเกมจากลิงก์เดียวกัน กรอกรหัสในช่องหน้าแรกแล้วกด **เข้าห้องเพื่อน** เพื่อนเข้าได้ทุกเมื่อระหว่างเกม
3. เกมทั้งหมดรันบนเครื่องของคนเปิดห้อง เครื่องเพื่อนส่งการกดปุ่มไป และรับภาพโลกกลับมา **คนเปิดห้องต้องเปิดเกมค้างไว้ที่หน้าจอ** ถ้าสลับแอปหรือพับจอ เกมของทุกคนจะหยุด
4. หลุดหรือรีเฟรชหน้าเว็บ กรอกรหัสเดิมแล้วจะได้ตัวละครเดิมพร้อมของในกระเป๋าคืน ระหว่างที่หลุด ตัวละครยืนนิ่งและซอมบี้ไม่สนใจ
5. คนเปิดห้องเป็นคนเซฟเกม (เก็บตัวละครของเพื่อนไว้ด้วย) เปิดห้องจากเซฟนั้นอีกครั้ง เพื่อนก็ได้ตัวละครเดิมคืน

เล่นหลายคนแล้วเปิดกระเป๋าหรือเมนูหยุดเกม เกมไม่หยุด ไม่มีปุ่ม ×2 / ×4 ยิงไม่โดนเพื่อน เพื่อนล้มช่วยพยุงได้ เพื่อนตายใช้ Resurrection Kit ชุบได้ ใช้ PeerJS (WebRTC) ถ้าเครือข่ายบางแห่ง (เช่น 4G บางเครือข่ายหรือ Wi-Fi บริษัท) ต่อกันไม่ได้ ให้ลองสลับไปใช้เครือข่ายอื่น

## หยุดเกม

กดปุ่ม ❚❚ มุมขวาบน หรือกด P / Esc เพื่อหยุดเกม ในหน้าหยุดเกมมีปุ่มเล่นต่อ เซฟเกม (บอกวันและเวลาที่บันทึก) เปิดปิดเสียง แจ้งบั๊ก และเซฟแล้วกลับหน้าแรก เกมจะหยุดเองเมื่อสลับแอปหรือพับหน้าเว็บ กลับมาจึงเจอหน้าหยุดเกมแทนการโดนรุม

**แจ้งบั๊ก (v0.6.2):** ปุ่มแจ้งบั๊กในหน้าหยุดเกมให้ผู้เล่นเล่าสั้น ๆ ว่าเกิดอะไรขึ้น แล้วแนบข้อมูลให้อัตโนมัติ: เวอร์ชัน วันและเวลาในเกม ระดับความยาก ความเร็ว HP อาหาร น้ำ ติดเชื้อ ของในกระเป๋า จำนวนซอมบี้และประชาชน สถานะประตู อุปกรณ์ (จอสัมผัสหรือไม่ ขนาดจอ user agent) และ error ล่าสุดไม่เกิน 5 รายการ ผู้เล่นเห็นข้อมูลทั้งหมดก่อนส่ง เลือกได้ว่าจะคัดลอกไปวางในแชต หรือเปิดหน้าแจ้งบั๊กบน GitHub (ต้องมีบัญชี)

เกมบันทึกอัตโนมัติทุก 15 วินาทีระหว่างเล่น และทุกครั้งที่ปิดหรือพับหน้าเว็บ เปิดเกมครั้งถัดไปจะมีปุ่ม **เล่นต่อ** บอกวันที่และเวลาในเกมที่เซฟไว้ เซฟเก็บในเบราว์เซอร์เครื่องนั้น (localStorage) มีช่องเดียว กด **เริ่มวันใหม่** จะลบเซฟเดิม และเซฟจะถูกลบเมื่อตัวละครตาย

## เทคโนโลยี

- Three.js r128 (โหลดจาก cdnjs) JavaScript ล้วน ไม่มีขั้นตอน build
- โค้ดเกมเป็น ES modules ใน `src/` (`index.html` มีแค่ HTML + CSS) texture ทั้งหมดวาดด้วยโค้ด ไม่มีไฟล์ภาพหรือเสียง
- ฟอนต์ Chakra Petch และ Big Shoulders Display จาก Google Fonts
- ตัวละคร: Quaternius Ultimate Modular Men / Women Pack (CC0) แปลงเป็น `.glb` ใน `assets/characters/` ด้วย `tools/build-characters.mjs` โหลด GLTFLoader และ SkeletonUtils ของ Three.js r128 จาก jsDelivr
- ปืน ของ และรถ (v0.14): แพ็ก Guns, Survival, Foods และ Cars ของ Quaternius (CC0, FBX) รวมเป็น `assets/props/props.glb` ด้วย `tools/build-props.mjs`
- PeerJS 1.5.4 (โหลดจาก jsDelivr ตอนเปิดหรือเข้าห้องครั้งแรกเท่านั้น) ใช้เซิร์ฟเวอร์กลางฟรีของ PeerJS แนะนำให้รู้จักกัน แล้วเครื่องคุยกันตรงด้วย WebRTC
- GitHub Actions รัน smoke test และ net test ทุก pull request และทุกครั้งที่ push เข้า `main` (`.github/workflows/smoke-test.yml`)
